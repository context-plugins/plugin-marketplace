# twilio SDK Plugin

Integrate and consume the **APIMatic-generated twilio SDK** across C#/.NET, TypeScript,
Python. The C#/.NET and Python layers cover the "APIMATIC v3.0" generic libraries (built on
`apimatic-*-core` / `apimatic/*-core-runtime` runtimes); the TypeScript layer covers the v4
generated SDK, which carries its own map instead. Works in **Claude Code**, **Cursor**, and
**VS Code**. Every SDK fact is grounded in the cloned SDK source and the bundled skills.

## How it works

Each supported language ships 8 skills: **`{lang}-getting-started`** (the
SDK-identity and source-navigation entry point) plus `client-initialization`, `authentication`,
`calling-endpoints`, `models`, `error-handling`, `configuration-resilience`, and `testing`. Your
coding agent loads the relevant skill by its description and grounds every SDK fact in the cloned
SDK source those skills point it to.

### C#/.NET — bundled SDK map + helper agent

The C# layer (inside `skills/dotnet/`) ships a generated **SDK map**
(`dotnet-twilio-getting-started/sdk-map.md` + `map/`) indexing every operation signature,
model, enum, union, and error type. The **`dotnet-integrate-twilio`** router skill routes all
C#/.NET SDK work to the single **`dotnet-twilio-sdk`** agent (.NET-only), which answers
every contract question by map lookup (cloning the SDK source only when the map can't settle a
fact) and produces a contract sheet before any code is written. Seven API-agnostic `dotnet-*`
skills layer usage guidance on top.

### TypeScript — SDK map ships inside the package

The TypeScript layer (inside `skills/typescript/`) targets the **v4** generated SDK, whose only
runtime dependency is `zod`. Its map is not bundled with the skills: the installed package itself
carries `sdk-map.md` + `map/operations/`, and `typescript-getting-started` is the lookup
layer that names every fact's owning source file and points the agent at that map. The
**`typescript-integrate-twilio`** router skill is the mandatory first step for TypeScript work —
it gates code behind a written contract sheet and requires the `typescript-*` companion skills the
sheet names.

## Supported languages

| Language | Skill prefix | Key runtime dependency |
|---|---|---|
| C#/.NET | `dotnet-` | `APIMatic.Core (NuGet)` |
| TypeScript | `typescript-` | `zod (npm)` |
| Python | `python-` | `apimatic-core (PyPI)` |

> The C#/.NET and Python layers apply to any SDK generated by the **APIMATIC v3.0**
> generic-library generators — that source carries a `// ... APIMATIC v3.0` header and depends on an
> `apimatic` core runtime package. The TypeScript layer applies to the **v4** generator instead,
> whose output depends on `zod` and ships its own SDK map.
